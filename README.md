# დავალება 1 — ელემენტების გაცენტვრა და განლაგება

## მიზანი

ისწავლო ელემენტების გაცენტვრისა და განლაგების ძირითადი CSS მეთოდები (`Grid`, `Flexbox`, `Position` და `Margin`) და შეძლო კონკრეტული სიტუაციისთვის ყველაზე ოპტიმალური მიდგომის შერჩევა.

## ძირითადი მოთხოვნები

- **სექციებად დაყოფა:** HTML ფაილში თითოეული მეთოდი მკაფიოდ უნდა იყოს გამოყოფილი ცალკე `<section>` ტეგით.
- **სათაურები სექციებში:** თითოეულ სექციას თავში უნდა ჰქონდეს სათაური (`<h2>`), რომელიც ზუსტად მიუთითებს, თუ კონკრეტულად რომელი მეთოდია გამოყენებული ამ სექციაში (მაგალითად: „მეთოდი 1: Margin“, „მეთოდი 2: Flexbox“ და ა.შ.).
- **მეთოდების გამოყენება:** დავალების ფარგლებში სრულად უნდა აჩვენო ოთხივე ძირითადი მეთოდის გამოყენება ელემენტების გასაცენტვრად.

---

## დავალება

შექმენი `index.html` და `style.css` ფაილები. HTML-ში გამოიყენე `<section>` ელემენტები და თითოეულ სექციას დაუმატე შესაბამისი სათაური.

### ნაწილი 1 — ჰორიზონტალური გაცენტვრა

1. შექმენი ცალკე `<section>` და შესაბამისი სათაური, რომელიც მიუთითებს `Margin` მეთოდზე.
2. შიგნით განათავსე `div` ელემენტი, რომელსაც ექნება ფიქსირებული სიგანე და სიმაღლე.
3. გააცენტრე ეს ელემენტი ჰორიზონტალურად margin-ის გამოყენებით.

### ნაწილი 2 — ვერტიკალური და ჰორიზონტალური გაცენტვრა Flexbox-ით

1. შექმენი ცალკე `<section>` შესაბამისი სათაურით, რომელიც მიუთითებს `Flexbox` მეთოდზე.
2. კონტეინერს მიანიჭე განსაზღვრული სიმაღლე.
3. შიდა ელემენტი ორივე მიმართულებით (ჰორიზონტალურად და ვერტიკალურად) გააცენტრე `display: flex`-ის და შესაბამისი გასწორების თვისებების (`justify-content` და `align-items`) გამოყენებით.

### ნაწილი 3 — ცენტრირება Grid-ის გამოყენებით

1. შექმენი ცალკე `<section>` შესაბამისი სათაურით, რომელიც მიუთითებს `Grid` მეთოდზე.
2. კონტეინერს მიანიჭე განსაზღვრული სიმაღლე.
3. შიდა ელემენტი ორივე მიმართულებით გააცენტრე `display: grid`-ისა და `place-items: center` (ან `align-content` / `justify-content`) გამოყენებით.

### ნაწილი 4 — პოზიციონირება (Position)

1. შექმენი ცალკე `<section>` შესაბამისი სათაურით, რომელიც მიუთითებს `Position` მეთოდზე.
2. კონტეინერს მიანიჭე `position: relative` და განსაზღვრული სიმაღლე.
3. შიდა ელემენტი გააცენტრე `position: absolute`-ის გამოყენებით.

## დამატებითი გამოწვევა

შექმენი ცალკე სექცია ბარათისთვის (Card), რომელსაც ექნება სათაური, აღწერა და ღილაკი. ელემენტები შიგნით განალაგე შენთვის სასურველი გაცენტვრისა და განლაგების მეთოდით ისე, რომ ბარათი იყოს ვიზუალურად მოწესრიგებული და ადვილად წასაკითხი.

---

## ჩაბარების პირობები

- HTML და CSS კოდი მოთავსებული უნდა იყოს ცალკე ფაილებში.
- კლასების სახელები უნდა იყოს სემანტიკური და გასაგები.
- თითოეული მეთოდისთვის შექმნილი სექცია მკაფიოდ უნდა იწყებოდეს სათაურით, რომელიც აფიქსირებს გამოყენებულ ტექნიკას.
- კოდში კომენტარებით მოკლედ ახსენი თითოეული მეთოდის მუშაობის პრინციპი.
